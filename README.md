# Agent Guild（エージェントギルド）

AIを使う前提を**掲載者が明示する**OSS Issue掲示板のローカルMVPです。依頼者・回答者とも基本無料です。GitHubの公開Issueを参照し、達成条件、AI利用方針の根拠、元Issueへのリンクを掲載します。UIは日本語中心の「クエストボード」ですが、実際の開発に必要な情報を優先しています。

## 起動

Node.js 22以上が必要です。

```bash
npm install
npm run build
npm run server
```

`http://127.0.0.1:46077` を開きます。開発中は別ターミナルで `npm run dev`（通常 `http://127.0.0.1:5173`）を起動できます。ViteはAPIをローカルサーバーに転送します。

```bash
npm run lint
npm test
```

## できること

- Issue一覧、キーワード・言語・ラベル・状態での絞り込み、詳細、GitHubの元Issueへの導線
- `https://github.com/owner/repo/issues/番号` に限定した公開GitHub API参照、取得失敗・不正URL・Pull Request混入・重複URLの検査
- 掲載者のAI利用申告と根拠、maintainer承認の**未検証の申告**を区別した表示。デモ見本はAI利用未確認と明記
- ローカルの役割切替（デモログイン）、回答者の作業開始・納品、掲載者が複数の回答から1件を選ぶ検収
- 任意のUSDC額、デモ用公開ウォレットアドレス、検収後の模擬支払、失敗と取消の履歴、二重支払防止

デモ見本は実募集ではありません。外部OSSのmaintainerがAI利用を許可したと推定しません。フォーム上の掲載者申告や承認根拠は本人確認済みの証明ではありません。GitHub API情報は掲載時のスナップショットで、元Issueの更新には自動追従しません。

## データと境界

入力した掲載、回答、ウォレット**公開アドレス**、支払状態はローカルの `data/listings.json` に保存されます。このファイルはGit管理対象外です。削除すると初期状態に戻ります。複数サーバープロセス間の同時更新や本番DB運用には対応しません。ローカルAPIは127.0.0.1にバインドしますが、**認証・認可・OAuthは未実装**です。画面の役割切替は模擬で、誰でも両役を操作できるため、外部公開や第三者投稿には使えません。秘密鍵・ウォレット生成・署名は扱いません。

USDCの報奨金は状態遷移だけの**sandbox/demo**です。資金預託、決済、実送金、チェーン接続は一切ありません。支払確定条件は仮仕様として「掲載者による検収」です。失敗後は公開アドレス登録後に再試行でき、支払済み・取消済みは再支払できません。現実の支払可否は判断していません。

本番化には認証と権限、GitHub maintainer承認の検証、DBと同時実行時の冪等性、監査ログ、スパム対策、チェーン・トークン、鍵管理、アップグレード権限、返金権限、検収主体、送金provider、KYC/法務と資金管理のレビューが必要です。Stripeの[stablecoin payouts](https://docs.stripe.com/connect/stablecoin-payouts)は現時点で米国プラットフォーム限定のprivate previewで、日本向けUSDC送金手段として採用済みではありません。資金移動に関する判断は[金融庁FAQ](https://www.fsa.go.jp/news/27/sonota/20151214-2.html)等を踏まえた専門レビューが必要で、無料・OSS・自己管理だけを理由に登録不要とは判断していません。
